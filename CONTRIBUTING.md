# Contributing to NOVA

Thanks for your interest in the NOVA Devnet project.

## Good first contribution areas
- Worker SDK and examples
- API schemas and validation
- GPU/AI inference adapters
- Tests and benchmarks
- Observability
- Documentation

## Workflow
1. Open or choose an issue.
2. Describe the change before large implementation work.
3. Never include credentials or wallet secrets.
4. Add tests for behavioral changes.
5. Submit a focused pull request.

The public repo follows an open-core model; some production orchestration and security modules remain private.
